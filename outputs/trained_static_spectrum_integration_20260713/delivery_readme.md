# Delivery Notes

This delivery is the ordinary-FBG BaySpec trained static full-spectrum edition.

Start the desktop software from:

`Desktop_App/TOUCH System - Trained Static Spectrum Twin.exe`

The app uses local port 8640. Close an older instance before starting another one.

Recommended operation:

1. Connect the BaySpec optical path and start the supported acquisition source.
2. Fully release the sensor.
3. Collect a stable recovery baseline and press Set baseline.
4. Confirm QA/baseline readiness.
5. Press one approximate P11-P33 region with a broad fingertip.
6. Read the trained position and light/normal/hard response level in the digital twin.

This is not the PD-voltage edition and not the earlier optical-intensity rule-based edition. It does not output calibrated force.
