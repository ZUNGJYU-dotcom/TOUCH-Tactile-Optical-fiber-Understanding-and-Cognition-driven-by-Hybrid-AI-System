Robot Nano Hand model provenance
================================

Source project: Robot Nano Hand
Author / project: The Robot Studio
Official repository: https://github.com/TheRobotStudio/robot-nano-hand
Source assembly: STEP/Complete_Hand_06_Final_Print_03e.STEP
License: MIT

The file robot_nano_hand_body.glb is derived from the official complete hand
assembly. The original thumb-tip component is intentionally omitted so the
existing TOUCH modified thumb sensor model can be fitted in its place.

The modified thumb sensor asset is maintained separately by this project and
is not taken from the upstream Robot Nano Hand release.
