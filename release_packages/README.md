# TOUCH Stable portable release packages

This directory contains the portable Stable application and the separate
BaySpec BS2BASE USB driver installer bundle for Windows x64 testing.

## Packages

- `TOUCH_Stable_v0.19.7_Full_Portable_OneFile_20260829.zip`
  - Stable version: `0.19.7`
  - Single-file application with the deployed model, runtime libraries,
    frontend, 3D assets, configuration, and BaySpec SDK bridge embedded.
  - SHA-256: `1D920589DCB8B581424C5AE64094AAA50496C0583422E062E6D6DACD42A94B31`
- `BaySpec_BS2BASE_USB_Driver_WIN64_20260829.zip`
  - Target hardware ID: `USB\VID_BA8C&PID_1688`
  - Includes the active CYUSB3 driver package, certificate, administrator
    install script, verification script, and Chinese instructions.
  - SHA-256: `4FA86011C6A6E34ADB926D9CEDDBB3D037F0C249D0149C41FA06CD4514F08BAA`

Both archives are stored with Git LFS. Download the complete files rather than
the small LFS pointer text shown by clients without Git LFS support.
